# SeRTial Schema Tools

Python tools for inspecting and visualizing SeRTial message schemas.

## Architecture

The tools are organized into modular components:

### Core Modules

- **`sertial_common.py`** - Shared data structures and utilities
  - `FieldInfo`, `BlockInfo`, `MessageSchema` data classes
  - `SchemaLoader` - JSON schema file loading and parsing
  - `SchemaAnalyzer` - Statistics and analysis functions
  - `LegacySchemaAdapter` - Compatibility layer for older schema formats

- **`sertial_cli.py`** - Terminal rendering module
  - `Colors` - ANSI color codes
  - `CLIRenderer` - Terminal-based visualization
  - Memory bar rendering
  - Colored field display
  - Summary tables

- **`sertial_gui_widgets.py`** - Reusable GUI components
  - `MemoryCanvas` - Canvas for memory layout visualization
  - `VariableFieldControl` - Slider control for variable-size fields
  - `MessageListBox` - Searchable message list
  - `FieldsTable` - Treeview for field information

### Tools

- **`sertial-inspect`** - CLI inspection tool
  - Summary view of all messages
  - Detailed view of specific messages
  - Colorized terminal output
  - Category filtering

- **`sertial-gui`** - Interactive GUI viewer
  - Visual memory layout
  - Variable-size field controls with sliders
  - Real-time size calculation
  - Block execution visualization
  - Padding analysis

## Usage

### CLI Tool

```bash
# Summary of all messages
sertial-inspect schemas.json --summary

# Detailed view of specific message
sertial-inspect schemas.json --message "Header<>"

# All messages with full details
sertial-inspect schemas.json --all

# Disable colors
sertial-inspect schemas.json --no-color --summary

# Filter by category
sertial-inspect schemas.json --category messages --summary
```

### GUI Tool

```bash
# Launch with schema file
sertial-gui schemas.json

# Or launch and browse for file
sertial-gui
```

## Features

### CLI Features
- Colored memory layout bars
- Field-by-field breakdown with padding info
- HybridMemoryMap block visualization
- Summary statistics table
- Copy block analysis

### GUI Features
- Interactive message browser with search
- Three-tier memory visualization:
  1. Struct layout (with padding)
  2. Packed layout (padding removed)
  3. Runtime layout (for variable-size types)
- Variable-size field controls:
  - Sliders for each dynamic field
  - Real-time size calculation
  - Max capacity visualization
- Detailed field table with sorting
- Category filtering
- Tooltips on memory regions

## Data Format

The tools expect JSON schemas generated by SeRTial's schema_generator:

```json
{
  "messages": [
    {
      "name": "MyMessage",
      "category": "messages",
      "sizeof_bytes": 64,
      "packed_size": 60,
      "has_padding": true,
      "has_variable_fields": false,
      "fields": [...],
      "blocks": [...],
      "memcpy_regions": [...]
    }
  ]
}
```

## Extending

### Adding New Visualizations

Extend `CLIRenderer` or `MemoryCanvas` classes:

```python
from sertial_cli import CLIRenderer

class MyRenderer(CLIRenderer):
    def custom_visualization(self, msg):
        # Add your visualization logic
        pass
```

### Custom Analyzers

Add analysis functions to `SchemaAnalyzer`:

```python
@staticmethod
def my_analysis(messages):
    return custom_metric
```
